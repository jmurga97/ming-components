# Matriz página–componente

La matriz agrupa wrappers compartidos cuando una página los consume indirectamente. “CSS Q” significa que la página hereda los tokens qmenut; “CSS R” añade utilities Tailwind `*-mc-*`. Todas las páginas autenticadas consumen también `AppShell` + `SidebarNav` desde el shell.

## Interacciones que deben tener prueba antes de migrar

1. Shell móvil: abrir/cerrar, Escape/overlay, focus trap cuando corresponda, restauración al trigger.
2. Select/TagPicker: flechas, typeahead, Escape, Tab, accessible label/error y estado controlled.
3. ConfirmAction: foco inicial seguro, pending focusable, cancel/Escape y restauración.
4. ResourceTable: select-all, selección filtrada, celdas con botones, navegación teclado y stacked mobile.
5. StatusRegion: live announcement, dismiss manual, auto-dismiss cancelado por interacción/reduced motion.
6. Menu de delivery: roving focus, Escape, click exterior y retorno de foco.
